# Template Chrome Extension

## Env

- React
- TypeScript
- Vite
  - CRXJS

## Getting Started

### 1. Set up a dev server.

```
yarn dev
```

### 2. Loading extensions into Chrome

1. Access the extension's management screen. ([chrome://extensions](chrome://extensions))
2. Turn on `Development mode`.
3. Select `/dist` in `Load unpacked`.
